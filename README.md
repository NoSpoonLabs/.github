# .github

Shared files of the TheBigNeo-AI repositories: the issue and pull request templates, reusable workflows and the
scripts they run.

## Secret scan

Reusable workflow `.github/workflows/secret-scan.yml`: gitleaks and a check for absolute local paths on the commits of
a pull request.

## Attribution text check

Tool attribution text does not belong in a commit, a pull request or a comment: `Generated by/with Claude Code`,
`Co-Authored-By: Claude`, `Claude-Session:` and session links. The patterns have one place, `PATTERNS` in
`scripts/attribution_check.py`; the workflow and the hook both use it.

### CI check

The reusable workflow `.github/workflows/attribution-check.yml` sets the commit status `Attribution text check` on the
head of a pull request: red when a commit message, the title, the body, a comment or a review contains attribution
text, green again once it is removed. A repository uses it with this file as `.github/workflows/attribution-check.yml`:

```yaml
name: Attribution text

on:
  pull_request:
    types: [opened, edited, synchronize, reopened]
  issue_comment:
    types: [created, edited, deleted]
  pull_request_review:
    types: [submitted, edited, dismissed]
  pull_request_review_comment:
    types: [created, edited, deleted]

permissions:
  contents: read
  pull-requests: read
  issues: read
  statuses: write

jobs:
  attribution:
    uses: TheBigNeo-AI/.github/.github/workflows/attribution-check.yml@main
```

Comment and review events run the workflow file of the default branch, so they take effect after the merge.

### commit-msg hook

`hooks/commit-msg` refuses a commit whose message contains attribution text. It needs `attribution_check.py` next to
it or in `../scripts`. Install it in a clone by copying both files (run in the clone; `<dotgithub>` is a clone of this
repository):

```
cp <dotgithub>/hooks/commit-msg <dotgithub>/scripts/attribution_check.py "$(git rev-parse --git-path hooks)/"
```

Without Python the hook lets the commit through; the CI check still runs.
